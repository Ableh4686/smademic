# Smademic Frontend

This is the frontend for the Smademic application, built with React and Vite. It provides a user interface for predicting academic risk and interacting with the system.

## Setup Instructions

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

## Technologies Used

- **React**: UI library
- **Vite**: Build tool and dev server
- **JavaScript**: Core logic
